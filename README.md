# Naming

ID 형식은 다음과 같다:
`종류(1자)` + `대분류(2자)` + `스토리(2자)` + `버전(1자)`

## 형식
### 종류
| 문자 | 의미 |
|---|---|
| `A` | Temp |
| `M` | Main Quest Stories |
| `X` | Exedra Quest Stories |
| `E` | Event Stories |
| `G` | Magical Girl Stories |

### 대분류
종류에 따라, `시리즈`, `연도`, `이름`이 된다.

### 버전
스토리 중에는 `일반` 또는 `나이트메어`로 분류되어있는 경우가 있다.

| 수 | 의미 |
|---|---|
| `0` | 해당 사항 없음 |
| `1` | 일반 |
| `2` | 나이트메어 |
